Machine zones

Pick a camera, click around a machine to draw its zone, then choose which machine it is. Two cameras can share a machine; their readings are merged.

Members & tags

Each member gets a printed tag (on a wristband, lanyard or key fob). Cameras read the tag, so there's no face recognition and no biometric data. Members who don't wear a tag still count toward machine usage as "guest".

Run it in a real gym

On any PC or mini-PC on the gym network (a single machine handles about 8–12 cameras at 8 fps):

cd gymtrack/server pip install -r requirements.txt # check a camera and grab a frame python -m gymtrack probe "rtsp://admin:PASS@192.168.1.64:554/Streaming/Channels/102" # print member tags python -m gymtrack tags 1 2 3 4 5 # go live (edit config.example.json first) GYMTRACK_TOKEN=change-me python -m gymtrack run config.example.json # or the full simulated demo python -m gymtrack demo

Only the tracking results are stored (sets, reps, times). Video never leaves the gym's network and isn't recorded.
